# Welcome Baek 개발 로드맵

> 기존 README의 프로젝트 목표, 개발 단계, 기술 기록을 이곳으로 옮겼습니다. 설치 방법과 사용 안내는 [README](../README.md)를 참고하세요.

Welcome Baek은 백준 온라인 저지(BOJ)의 문제 풀이 환경을 개선하기 위한 Chrome 확장 프로그램입니다.

기존 백준은 문제 확인 페이지와 코드 제출 페이지가 분리되어 있습니다. Welcome Baek은 문제 페이지에 코드 에디터를 통합하여, 프로그래머스나 코드트리처럼 하나의 화면에서 문제를 확인하고 코드를 작성할 수 있는 환경을 제공합니다.

## 1. 프로젝트 목표

- **통합된 문제 풀이 환경:** 문제와 코드 에디터를 좌우 분할 화면으로 제공
- **편리한 코드 작성:** 문법 강조, 자동 들여쓰기, 다양한 에디터 테마 지원
- **안정적인 코드 보존:** 백준 로그인 세션과 독립적으로 작성 중인 코드 저장
- **간편한 제출:** 작성한 코드를 백준 공식 제출 페이지와 연동
- **경량화:** 최소한의 라이브러리와 리소스로 브라우저 부담 최소화

별도의 회원가입이나 자체 백엔드 없이 사용할 수 있는 확장 프로그램을 목표로 합니다.

## 2. 기술 스택

| 구분        | 기술               |
| ----------- | ------------------ |
| Language    | TypeScript         |
| UI          | HTML, CSS          |
| Code Editor | CodeMirror 6       |
| Build Tool  | Vite               |
| Extension   | Chrome Manifest V3 |
| Storage     | Chrome Storage API |
| CI/CD       | GitHub Actions     |
| Deployment  | Chrome Web Store   |

초기 버전에서는 React와 별도의 백엔드를 사용하지 않습니다.

## 5. 개발 원칙

1. **Lightweight:** 확장 프로그램 용량과 브라우저 리소스 사용량 최소화
2. **User First:** 기존 백준 이용 경험을 유지하면서 편의성 개선
3. **Privacy:** 작성 코드는 기본적으로 사용자 브라우저에 저장
4. **Modularity:** 코드 편집, 저장, 제출, 실행 기능을 독립적으로 구성
5. **Maintainability:** 백준 페이지 구조 변경에 대응하기 쉬운 설계

## 6. 현재 개발 상태

**Version:** 1.0.0

**Current Phase:** Chrome에서 Java 11 로컬 컴파일 및 실행

Phase 4의 저장 UI는 사용자 확인을 마쳤습니다. 현재 코드를 새 탭의 백준 제출 화면으로 전달하는 기능을 추가했습니다.
`npm run typecheck`, `npm run build`, `npm test`로 검증합니다. 자동 테스트는 먼저 빌드된 `dist`도 검사합니다.

**Next Step:** 실제 백준에서 Java 11 풀이 호환성과 실행 시간을 확인합니다.

디자인은 코드트리의 얇은 상단 도구 모음과 넓은 편집 영역을 참고했습니다. 저장 안내는 언어 선택 오른쪽, 위치 반전은 중앙 구분선 상단에 있습니다.
하단에는 테스트 케이스·실행 결과·코드 실행·코드 제출을 배치했습니다. 테스트 패널은 드래그로 높이를 조절하고 아래로 내려 닫습니다.
테스트 케이스는 문제별로 저장됩니다. Java를 선택하고 **코드 실행**을 누르면 등록된 모든 케이스를 순서대로 실행하고, 결과 탭에서 케이스별 출력과 통과·실패·오류를 확인할 수 있습니다. 실행 시작 시 코드와 케이스의 복사본을 사용하며, 한 케이스가 실패해도 나머지를 계속 실행합니다. 전체 실행 중에는 진행률과 로딩 아이콘을 표시하고 코드 편집과 언어 변경을 잠급니다. Java 11 실행기는 확장 프로그램에 포함되어 별도 JDK나 실행 도우미가 필요 없습니다. 코드와 입력은 브라우저 내부에서 처리합니다. 현재는 각 케이스마다 독립적인 Java 환경에서 컴파일·실행하며, 실행 제한은 케이스당 5초입니다. 실제 백준 채점 시간과 호환성에는 차이가 있을 수 있습니다.

Java 자산의 버전과 재생성 방법은 [런타임 문서](../vendor/ristretto/README.md)에 있습니다.
`npm run preview:ui`를 실행하면 실제 dist를 사용하는 로컬 화면을 확인할 수 있습니다. 먼저 `npm run build`가 필요합니다.
