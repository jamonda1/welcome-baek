# Welcome Baek 개인정보처리방침

Welcome Baek은 백준 문제 페이지에서 코드 작성, 테스트, 제출을 돕는 Chrome 확장 프로그램입니다.

확장 프로그램은 현재 백준 문제의 번호와 예제 입력·출력을 읽습니다. 문제 번호별로 작성한 코드와 테스트 케이스를 브라우저에 저장하며, 선택한 언어·테마·화면 설정도 같은 기기에서 복원합니다. Java 코드 실행과 테스트 입력 처리는 브라우저 안에서 이루어집니다.

사용자가 ‘코드 제출’을 누르면 작성한 코드와 선택한 언어가 백준 제출 화면에 채워집니다. 코드는 사용자가 백준의 최종 제출 버튼을 누르면 백준으로 전송됩니다. 확장 프로그램은 개발자의 서버로 코드나 테스트 입력을 보내지 않으며, 백준 비밀번호, 로그인 쿠키, 전체 방문 기록을 수집하지 않습니다.

이 기기에 저장된 확장 프로그램 데이터는 Welcome Baek을 제거하면 삭제됩니다. 개인정보 관련 문의는 Welcome Baek GitHub Issues에 남길 수 있습니다. 이슈는 공개되므로 개인 정보나 비공개 코드는 포함하지 마시길 바랍니다.
